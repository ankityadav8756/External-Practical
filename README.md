# 💳 Pricing Card UI

A simple and responsive Pricing Card UI project created to practice HTML and CSS.

The project displays three different pricing plans — Basic, Standard, and Premium — in a clean and simple card-based layout.

## 📸 Project Preview

![Pricing Card UI](./screenshot.png)

## 📌 Project Overview

This project demonstrates how to create attractive pricing cards using HTML and CSS.

Each pricing card contains:

- Plan name
- Monthly price
- Storage information
- Number of users
- Support availability
- Sign Up button

The three available plans are:

### 🟢 Basic
- $9.99/month
- 10GB Storage
- 1 User
- No Support

### 🔵 Standard
- $19.99/month
- 50GB Storage
- 5 Users
- Phone & Email Support

### 🟣 Premium
- $49.99/month
- 100GB Storage
- 10 Users
- 24/7 Support

## ✨ Features

- Clean pricing card design
- Three pricing plans
- Simple and user-friendly interface
- Different features for each plan
- Sign Up buttons
- Card shadows and rounded corners
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
